# コンビニ巡回ルート

指定した地点の周辺（半径 1〜30km、初期値 5km）にあるローソン・セブン-イレブン・ミニストップ（・ファミリーマート）を検索し、
**車で全店舗を回る最短の順番**を計算して Google マップのナビに引き渡す Web アプリです。
くじ・限定グッズ集めを想定し、店舗ごとに「購入／売切れ／取扱なし」を記録できます。

API キー不要・完全無料で動きます（ビルド不要の静的サイト）。

## 使い方

画面は地図の下（PC では右）のタブ「① ⚙ 設定 → ② 🗺 エリア → ③ 🗓 計画 → ④ 🚗 巡回」で、左から右へ進みます。
どのタブも、次のタブへは下の「次へ」ボタンで進みます。画面の組み立ては電車版の [ConveniRadar](https://github.com/tyra0119/ConveniRadar) にそろえています。

1. **設定**：くじ・グッズ名、コンビニの種類、出発時刻・滞在時間、「出発地へ戻る」「記録済みの店を除く」
2. **エリア**：出発地（📍 現在地／🗺 地図の中心／住所／地図タップ）と半径。「🔍 店舗を検索」で範囲内の店を探す
   - 「🗺 地図の中心」を選んでいる間は、エリアタブで地図を動かすと出発地と範囲も一緒に動きます
3. **計画**：「🗓 計画を作る」で最短の回る順番を計算（店舗をまだ検索していなければ先に検索）→ 回る店の一覧 →「次へ：巡回へ →」
   - 一覧のチェックを外した店は、次に計画を作るときに外れます
4. **巡回**：「▶ 次へ」で Google マップのナビが起動。店ごとに「購入／売切れ／取扱なし／スキップ」とメモを記録
   - 記録ボタンは次に回る店だけ開いていて、ほかの店は「記録 ▾」で開く。店の行を押すと地図でその店が点滅する
   - 寄れない店が出たら「🔄 現在地から残りの店で組み直す」
   - 「📧 実績を送る」で、記録をメールアプリ・共有メニュー・コピーで送れる（サイトから自動で送ることはない）

上のバーの「🗑 クリア」で、出発地・見つけた店・計画をまとめて消せます（設定とくじの記録は、確認でチェックを入れたときだけ消します）。

記録・店舗・計画はブラウザ（localStorage）に保存されるので、途中でページを閉じても続きから再開できます。

## 仕組み

| 役割 | 使っているもの |
|---|---|
| 地図表示 | Leaflet ＋ OpenStreetMap タイル |
| 住所検索 | 国土地理院 住所検索 API（失敗時 Nominatim） |
| 店舗データ | OpenStreetMap（Overpass API） |
| 道路距離・所要時間 | OSRM 公開デモサーバー（失敗時は直線距離×1.35で概算） |
| 巡回順の計算 | 15店舗以下：Held-Karp 法で**厳密な最短**／それ以上：最近傍法＋2-opt |
| ナビ | Google マップ URL（経由地は1リンク9か所ごとに分割） |

所要時間（運転時間）が最小になる順番を求めています。

## ローカルで動かす

```bash
python -m http.server 8123
```

ブラウザで http://localhost:8123 を開きます。

## スマホで使う（GitHub Pages）

現在地の取得には HTTPS が必要です。GitHub Pages なら無料で HTTPS 公開できます。

1. このリポジトリを GitHub に push
2. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして保存
3. `https://<ユーザー名>.github.io/lawson/` をスマホで開き、ホーム画面に追加

## 注意点

- OpenStreetMap の店舗データは有志による登録のため、**載っていない店舗・閉店済みの店舗**があり得ます。
  閉店済みの店は、計画の一覧のチェックを外すか、地図の店の「計画から外す」で外してください。
- OSRM 公開デモサーバーは個人利用の範囲にとどめてください（大量アクセス不可）。
- Google マップ URL の経由地数はモバイルブラウザだと制限が厳しい場合があります。
  うまく開けないときは「▶ 次へ」で1店ずつナビしてください。
